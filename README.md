**Objective**

These Python scripts allow to extract records from the StaffAny API and post them to a Mongo database.

**Requirements**

* Python installed on the machine running this application.
* Credentials for accessing the StaffAny API - you need to request to StaffAny for your credentials and URLs.
* Credentials for writing to a MongDB database - this database will be used for storing the data extracted from the StaffAny API.

**How to run this application**

* Copy the file `config-sample.py` to `config.py`.
* Edit `config.py` with your credentials and defaults.
